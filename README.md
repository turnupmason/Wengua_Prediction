## 编辑底线

1. 「极大/大/中/小/极小」源强五档与十档分数属于**后台分析标签**；消费者第一屏只使用正式约定的「吉局/凶局」和标题（如「大吉：邪退正复」），正文绝不朗读一串分档。
2. 专业推理顺序：病宫事实 → 被问测人主用神/辅宫 → 天心与乙奇医药 → 跨宫施受方向及真正有效性 → 值符、空墓刑迫、伏吟反吟、应期 → 有理有据的合断。突出真正关键证据，保留不利证据，不虚构病因、实际愈期或现实医学结果。
3. 「势待核」不是文学阻断理由：只保留为**源事实核验状态**；写作时不能把未核强弱冒充确认。无新证据不改变冻结等级。「微恙」与「不凶不吉」是**中性同级**，不报冲突。
4. 每份文稿必须保留来源事实锁（原文SHA、证据SHA、版本、四柱、节气、父亲甲子遁戊等）和完整第二屏专业论述，GPT 候选必须由人审通过才允许 published。
5. 对「独一无二」的正确理解：**每个 record 有独立身份和独立审稿稿件，不复用其它条件的断词**。事实真相相同可使用相同术语，不得为了去重发明差异；用重复率检测提高编辑质量。
6. 上架仅使用 `approved` 记录生成的 **SQLite 离线资源**，而不是 App 在线抓 GitHub。构建时固定 commit/资源 SHA 和 V8 模型版本，iOS 根据完整条件查找，未命中就由经验证的 Swift 算法计算并使用原正版断词（不能随意套用类似盘文章）。
7. 本仓库公开：不提交原两书完整原文、私密问事记录、用户6000原始Excel或尚未核准的大量文学稿。这里只保留可公开的原创审稿样本、索引、规则、脚本；源原文和完整修改历史本地加密/版本保留。
