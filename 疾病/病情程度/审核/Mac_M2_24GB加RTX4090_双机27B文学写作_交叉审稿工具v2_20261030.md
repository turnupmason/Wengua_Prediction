## 双机核心命令

```bash
# Mac先安装/启动Ollama，4090端也独立装好并开启Ollama。
ollama pull qwen3.5:27b-q4_K_M
# PC的另一个终端也运行 ollama pull qwen3.5:27b-q4_K_M
# Mac独立Terminal保持：
ssh -N -L 11435:127.0.0.1:11434 PC用户名@PC内网IP
# 如旧版Mac已 init，不用重复导入：
python3 wengua_mac_batch.py write-dual --limit 10
python3 wengua_mac_batch.py review-dual --limit 10
python3 wengua_mac_batch.py audit
python3 wengua_mac_batch.py status
# 4090挑战35B：两条dual指令都增加：
# --gpu-model qwen3.5:35b-a3b-q4_K_M --gpu-ctx 8192
# 已验收后：
python3 wengua_mac_batch.py write-dual --limit 200
python3 wengua_mac_batch.py review-dual --limit 200
# 真正逐条518400独立文学稿，不误把38016证据组底稿视为518400成品：
python3 wengua_mac_batch.py write-dual --mode cases --case-start 31 --limit 10
python3 wengua_mac_batch.py review-dual --mode cases --limit 10
```
